# Security Policy

## Supported Versions

We actively maintain and provide security patches for the following versions of GYM Pose AI:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

The GYM Pose AI team takes security seriously. If you discover a security vulnerability, please bring it to our attention immediately so we can address it responsibly.

**Please do NOT report security vulnerabilities via public GitHub issues.**

Instead, please report security issues privately:
- **Email:** Send details to [somgautam2077@gmail.com](mailto:somgautam2077@gmail.com) with the subject `[SECURITY] GYM Pose AI Vulnerability Report`.
- Include:
  - Description of the vulnerability.
  - Steps to reproduce or proof-of-concept code.
  - Potential impact and affected components.
  - Any proposed mitigations or fixes.

### Our Response Process
1. **Acknowledgement:** We will acknowledge receipt of your report within 48 hours.
2. **Assessment:** We will confirm the vulnerability and assess its severity.
3. **Fix & Release:** We will develop a fix and release a patched version as soon as possible.
4. **Public Disclosure:** Once a patch is released, we will coordinate public disclosure and credit the reporter (unless you prefer to remain anonymous).

Thank you for helping keep GYM Pose AI secure!
